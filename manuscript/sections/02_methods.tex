The dataset used in this study comprised 28 closed-shell organic molecules from Thiel's excited-state benchmark set \cite{thiels2008benchmark}. 
These molecules were selected to cover the most important chromophores in organic photochemistry, and comprise hydrocarbons, heterocycles, carbonyls, amides and nucleobases (Figure~\ref{fig:benchmark-molecules}).
The published Cartesian nuclear coordinates were referenced directly and used without further optimisation. 

For each molecule, Restricted Hartree-Fock calculations were performed using PySCF \cite{pyscf2018,pyscf2020} with the STO-3G basis set, forming a set of canonical molecular orbitals there were optimised once and used consistently throughout the study.
Active spaces (denoted $n_e e\, n_{\mathrm{o}} o$) comprised the $n_e / 2$ occupied molecular spatial orbitals closest to the HOMO and the $n_{\mathrm{o}} - n_e / 2$ virtual molecular spatial orbitals closest to the LUMO. The remaining occupied orbitals were treated as frozen and doubly occupied, while the remaining virtual orbitals were excluded from calculations.

\subsection{Quantum Workflow}
In this study, all quantum-circuit calculations were performed using classical simulations implemented with the Qibo and Qibochem \cite{qibo2021,qibochem2024zenodo} frameworks. 
Ideal noiseless simulations were employed throughout, with finite-sampling noise introduced only in the sections involving a limited number of measurement shots.
The same electronic hamiltonian (\cref{eq:electronic-hamiltonian}) was used for all quantum calculations, and all fermionic operators were mapped to qubit operators via the Jordan-Wigner (JW) transformation.

For finite-shot calculations, the Pauli terms contributing to the projected matrices were first grouped globally (across $\mathbf{H}$ and $\mathbf{S}$) into qubit-wise commuting (QWC) measurement sets.

These samples were used to estimate the expectation values for the projected matrices.
