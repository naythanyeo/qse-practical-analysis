\subsection{Molecular Benchmark and Electronic-Structure Calculations}
\begin{figure}[htbp]
    \centering

The dataset used in this study comprised 28 closed-shell organic molecules from Thiel's excited-state benchmark set \cite{thiels2008benchmark}. 
These molecules were selected to cover the most important chromophores in organic photochemistry, comprising hydrocarbons, heterocycles, carbonyls, amides and nucleobases (Figure~\ref{fig:benchmark-molecules}).
The published Cartesian nuclear coordinates were referenced directly and used without further optimization. 

For each molecule, Restricted Hartree-Fock (RHF) calculations were performed using PySCF \cite{pyscf2018,pyscf2020} with the STO-3G basis set. The respective optimized canonical molecular orbitals were used throughout the study.
Active spaces (denoted $n_e e\, n_{\mathrm{o}} o$) comprised the $n_e / 2$ occupied molecular spatial orbitals closest to the HOMO (inclusive) and the $n_{\mathrm{o}} - n_e / 2$ virtual molecular spatial orbitals closest to the LUMO (inclusive). For example, a $6e6o$ active space is defined as HOMO-2, HOMO-1, HOMO, LUMO, LUMO+1 and LUMO+2 in this study. The remaining occupied orbitals were treated as frozen and doubly occupied, while the remaining virtual orbitals were excluded from calculations.

Exact reference energies and wavefunctions were obtained from complete active-space configuration interaction (CASCI) diagonalization of the active-space Hamiltonian in PySCF.

By default, UCCSD was used as the reference ansatz throughout this study. Additional ansatz classes were considered in \cref{sec:ansatz-dependence}, namely UCCSDSinglet, UCCGSD, and $k$-UpCCGSDSinglet \cite{Anand2022UCCReview,Diniz2021GeneralisedAnsatzAdaptations, Lee2018GeneralisedAnsatzOriginal} for $k=1,2$ and $3$ in the 6e6o active space. 
The corresponding excitation operators defining each ansatz are provided in \cref{sec:si-ansatz-classes}.
The variational parameters $\boldsymbol{\theta}$ were optimized using the L-BFGS-B algorithm by minimizing the Hamiltonian expectation value obtained from exact statevector simulation (\cref{eq:electronic-hamiltonian}).
Unless otherwise stated, all UCC operators were implemented using the first-order Suzuki Trotter product approximation.

The VQE-optimized ground-state circuits were then used as the reference states for QSE calculations. 
As introduced above, QSE constructs a trial subspace by applying a set of expansion operators to the reference state. Following the original QSE formulation \cite{mcclean2017qse}, we restricted the expansion operator pool to one-body fermionic operators. 
To enable a spin-resolved analysis of the excited-state spectrum, these operators were further spin adapted to construct separate singlet and triplet operator pools. This allows low-lying singlet and triplet states to be targeted and analyzed independently.

For statevector calculations, the optimized VQE circuits were simulated to obtain the corresponding quantum states, from which the required expectation values and projected matrix elements were evaluated exactly. For finite-shot calculations, the Pauli terms contributing to both $\mathbf{H}$ and $\mathbf{S}$ were globally grouped into qubit-wise commuting (QWC) measurement sets. The resulting measurement outcomes were then used to estimate the Pauli expectation values and, consequently, the projected matrix elements.
