# Data

This directory combines tracked molecular inputs with externally archived calculation results. Complete the [environment setup](../README.md) before processing data.

## Tracked Data

- `28_mols/`: molecule geometries as `.xyz` files.
- `parameters/hf_data/`: cached canonical orbitals, integrals, and Hartree-Fock metadata in NPZ files.
- `parameters/vqe_params/`: optimised VQE parameters and energies in NPZ files.
- `table_data/Orbital_Character.csv`: curated molecular metadata, supplied as input.
- `table_data/uccsd_low_lying_state_errors.csv`: reference errors and projections, regenerated by notebook 01.
- `table_data/exact_casci_dominant_transitions.csv`: reference transition descriptions, regenerated by notebook 06.

The two generated CSVs can be inspected without running the notebooks. Rerunning their producing cells overwrites them; the orbital-character CSV is not regenerated.

## External Data

Download the numerical datasets from [Figshare version 2](https://doi.org/10.6084/m9.figshare.33950287.v2).

| Archive | Contents | Required for |
| --- | --- | --- |
| `raw_matrices.zip` | Raw QSE Hamiltonian, overlap, spin, and doubles matrices generated by the scripts | Rebuilding processed dataframes |
| `processed_dataframes.zip` | Three pickle files produced by notebook 00 | Starting directly with notebook 01 |
| `wavefunctions.zip` | Exact CASCI energies/vectors and QSE basis-state matrices | Both routes |
| `visualise.zip` | Molecular-orbital cube files | Optional orbital visualisation |

Each archive contains its named top-level folder. Extract into `data/`, preserving subdirectories: for example, `wavefunctions.zip` should create `data/wavefunctions/`, not `data/wavefunctions/wavefunctions/`.

The complete layout is:

```text
data/
  28_mols/
  parameters/
    hf_data/
    vqe_params/
  table_data/
    Orbital_Character.csv
    uccsd_low_lying_state_errors.csv
    exact_casci_dominant_transitions.csv
  wavefunctions/
    pyscf_casci/
    qse_state_matrices/
  raw_matrices/
    SV_hamiltonian/
    SV_spin/
    shots_hamiltonian/
    SV_hamiltonian_select_doubles/
      ov_doubles/
      frontier_doubles/
  processed_dataframes/
    sv_qse_data.pkl
    shots_qse_data.pkl
    sv_qse_ov_doubles_data.pkl
  visualise/
  cache/
```

## File Contents

Raw NPZ files under `raw_matrices/` hold calculation metadata and projected Hamiltonian/overlap or spin matrices, generated directly by the scripts. The `wavefunctions/` directory holds exact CASCI energies and determinant vectors, and QSE basis-state matrices used for projection analysis.

Finite-shot files also contain sampling information and repeated matrix estimates. Processed pickle files combine records into pandas dataframes. 

The `frontier_doubles/` dataset contains historical exploratory calculations, retained for completeness but excluded from notebook 00's standard processed outputs. The current doubles analysis uses `ov_doubles/`.

`visualise.zip` contains eight frontier molecular orbitals per molecule, HOMO-3 through LUMO+3. These cube files are optional and are not read by the analysis notebooks.
